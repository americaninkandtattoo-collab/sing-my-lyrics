SingMyLyrics

Rule: Your words stay yours. SML is built to protect creator ownership.

Flow: Write lyrics → pick style → Create → manage versions → Trash safety net (30 days) → Restore.

This is a local prototype: tracks are stored in your browser (localStorage) so the UI works even before backend wiring.

What works right now:
  • Create generates a new track card instantly
  • Now Playing + queue + player controls
  • Export Lyrics PDF + Sheet placeholder PDF
  • Soft-delete to Trash with days-left counter + Restore
  • Sidebar collapse
